# CLI features

<!-- begin section -->
#### G4X-helpers provides the following CLI commands:

- [viewer](./viewer.md) : export or import metadata for `g4x-viewer.zarr` stores
- [redemux](./redemux.md) : reprocess G4X-data with a new transcript manifest 
- [resegment](./resegment.md) : reprocess G4X-data with a new segmentation 
- [migrate](./migrate.md) : migrate legacy data to the latest G4X-data schema and G4X-viewer format
- [validate](./validate.md) : validate G4X-data file and folder structure
