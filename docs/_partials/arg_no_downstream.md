### `--no-downstream`
_type_ : <span class="acc-2-code">`flag`</span>  
_default_ : `not set`

> Runs only the primary reprocessing step for the command and skips downstream single-cell processing and `g4x-viewer.zarr` generation.

> Use this option when you want to inspect intermediate outputs or chain multiple processing steps before regenerating final single-cell and viewer outputs.
